# CodeAlpha_BasicChatbot

Task 4 of the **CodeAlpha Python Programming Internship**.

A simple rule-based chatbot that replies to predefined user inputs.

## Features
- Responds to greetings ("hello", "hi"), "how are you", and "bye"
- Extra replies: name, help, thanks
- Case-insensitive and ignores extra spaces
- Handles empty and unknown inputs
- Runs in a loop until the user says "bye"

## Concepts Used
`if-elif`, functions, `while` loop, input/output, string methods

## How to Run
```bash
python chatbot.py
```
Requires Python 3.6+. No external libraries needed.

## Sample Conversation
```
You: hello
Bot: Hi!
You: how are you
Bot: I'm fine, thanks!
You: bye
Bot: Goodbye!
```
